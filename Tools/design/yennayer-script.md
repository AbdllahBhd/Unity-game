# Timucuha n Yennayer — script

Date: 2026-10-19. Status: draft for the user's correction. English is the master text.
Taqbaylit (TQ) is my draft in Latin letters and **must be corrected by the user**; French
(FR) and Arabic (AR) are my translations. Each line has an id for the game's text table.

Speakers: **Jida** (grandmother), **Girl**, **Boy**, **Children** (both), **Teryel**.
Mqidec never speaks. Jida's mood is in brackets: telling, teasing, hushed.

Formulas stay in Taqbaylit in every language.
