# The Green Harvest — browser prototype on the original art

A playable phone-shaped prototype of Hollow Night built on the user's original handmade
PSD art, with a new story. Design record: `../original-prototype-spec.md`.
Unity scripts, scenes and sprites are not touched.

## Play

```bash
python3 -m http.server 8877 --bind 127.0.0.1 --directory Tools/design
```

Open `http://127.0.0.1:8877/original/` (on a phone on the same network, bind to
`0.0.0.0` and use the computer's address). Opening `index.html` directly also works.

- Drag anywhere and release to launch Izan. While you aim, the pumpkins freeze; while
  you rest, they keep hunting.
- Tap while flying to dash once, or to let go of a zip thread. Space also dashes,
  R restarts, Esc pauses.
- Each stage has three pumpkins; each one you smash is a star. The door always ends
  the stage, except stage 14 where it opens when the Weaver falls.
- The first time an object appears, a teaching card pauses the game and spotlights it.
  The Owl also remarks on first smashes, deaths and tricks.
- Sound is synthesized in `sfx.js` (wind, hoots, smashes, the bell). A button on the
  title and pause screens mutes it.
- Progress (stars, seen story screens) is kept in this browser's local storage.
  All stages are unlocked so any stage can be reviewed.

## Files

| File | Purpose |
|---|---|
| `index.html`, `styles.css` | Title, stage map, story, stage HUD, pause and result screens |
| `app.js` | Screen flow, pointer input, camera, effects, saved progress |
| `art.js` | Draws the exported PNGs: part-animated rabbit, Weaver, pumpkins, doors, backdrop, story scenes |
| `levels.js` | The fourteen stages, each tagged with the mechanic it teaches |
| `story.js` | Prologue, the line before each stage, the scenes after stages 4, 10 and 14, teaching cards, Owl remarks |
| `sfx.js` | WebAudio sound synthesis: `HNSfx.unlock/play/ambience/setMuted` |
| `routes.js` | Generated: one verified three-star route per stage, at human pace |
| `find-routes.js` | Beam search that writes `routes.js`. Waits 1.2 s at rest before every launch (pumpkins hunting meanwhile) and 0.15 s before any dash, so a route needs no reflexes. `node find-routes.js 6 --seed 3` reruns one stage |
| `verify-routes.js` | Replays every route with the same pauses; fails unless all three pumpkins are smashed and the stage's lesson is used |
| `assets/` | Generated by `Tools/export_original_art.py`; do not edit by hand |

The engine is shared with the comparison prototype: `../prototype/game.js`. This game
turns on its newer rules per level (`rules`, `web`, `trampoline`, `zip`, `drop`, `post`,
`seesaw`, `spider`, rolling pumpkins, boss bombs) and the `aim` pursuit and `lively`
hunter options, so the comparison prototype behaves as before.

| # | Stage | Teaches |
|---|---|---|
| 1 | The Lifted Stone | Launch |
| 2 | They Go Around | Pumpkins hunt; aiming freezes them |
| 3 | The Crypt Door | Dash |
| 4 | The Balanced Stone | Seesaw: land hard, the other end throws its pumpkin |
| 5 | Threads That Swing | Ride a swinging stone (moving stones crush pumpkins) |
| 6 | Silk | Sticky web: held once, launch again |
| 7 | Bounce | Tight web: flung back along its normal |
| 8 | The Long Thread | Zip thread: slide, smash what sits on it, tap to let go |
| 9 | The Frayed Thread | Falling stone crushes a pumpkin between grave posts |

| 11 | Bowling | Rolling pumpkin bowls over others and breaks on a hard fall |
| 12 | The Cellar | Descent combining web, falling stone and swing |
| 13 | The Family Cauldrons | Cannons |
| 14 | The Weaver | Boss with silk bombs |

## Regenerate the art

```bash
uv run --with 'psd-tools[composite]' --with pillow python3 Tools/export_original_art.py
```

Reads `Assets/graphics/Texture/*.psd` (plus the cauldron from the Halloween pack and the
fonts in `Assets/Resources/HN/Fonts`) and writes only into `assets/`.

node --test Tools/design/prototype/game.test.js

## Honest limits

- Browser physics approximates Unity Physics2D. A route here is not proof of a Unity route.
- Routes prove each stage can be finished with three stars. They do not prove it is fun
  or fairly difficult; that needs people playing it.
- Layer effects such as outer glows did not survive the PSD export; the renderer adds
  glows in code. The house on the hill, the ground strip, grave posts, silk webs and silk
  bombs are drawn in code because the original art has no such pieces.
- Sound is synthesized and was checked for errors, not auditioned by ear.
